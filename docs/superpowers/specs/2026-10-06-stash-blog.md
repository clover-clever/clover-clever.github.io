# MOSFET Thief's Stash — Design brief

## Approved outcome
- Public GitHub Pages blog at https://clover-clever.github.io.
- Title: MOSFET Thief's Stash
- Subtitle: Whatever sparks curiosity
- Jekyll Chirpy starter, Catppuccin Mocha, fixed dark mode.
- Korean interface and Asia/Seoul timezone.
- Author display name: MOSFET Thief.

## Content
- 모터제어·전력전자 → 모터드라이브 / 컨버터.
- 이모저모 → 수학 / 물리·과학.
- Preserve Chirpy's two-level category semantics and normal post pagination.
- Show these collections clearly before articles are published, without broken archive links.
- Introductory series: RL 회로에서 PMSM 전류제어까지.
- Prepare the first technical article as an unpublished draft.
- Do not invent completed research, measured results, or personal credentials.

## Presentation and maintenance
- Keep Chirpy navigation, search, feeds, math and syntax highlighting.
- Apply Mocha across typography, panels, controls and code colors.
- Title uses two lines; Stash receives the accent color.
- Use minimal local template overrides and retain existing build workflow/dependencies.
- Reuse a simple original vector mark for avatar and favicons.
- About and repository writing guide explain the blog and draft-to-post flow.
